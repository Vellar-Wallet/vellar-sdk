    maxAmount

    maxAmount: bigint

    Hard ceiling in the asset's base units. The client refuses to SIGN a payment whose required amount exceeds this. NOTE: a client-side guard against an over-charging server — NOT the budget. The durable budget is the on-chain spending-limit policy attached to the signing key.
