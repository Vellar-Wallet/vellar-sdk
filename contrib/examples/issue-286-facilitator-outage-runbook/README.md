# Facilitator outage runbook

A runbook for responding to a degraded or unreachable `vellar-facilitator`
service, covering detection signals, consumer-facing guidance (including
expected SDK error types), and escalation.

Contributed for [issue #286](https://github.com/Vellar-Wallet/vellar-sdk/issues/286).

See [FACILITATOR-OUTAGE-RUNBOOK.md](./FACILITATOR-OUTAGE-RUNBOOK.md) for the
runbook itself. It is submitted here because contributor PRs may only touch
`contrib/`; see the placement note at the top of that file for how it should
move to sit alongside `CONTRIBUTING.md` at the repo root.
